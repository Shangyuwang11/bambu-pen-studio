Update compatibility
The 0.22.1 updater reads GitHub's latest stable release, compares patch versions
and validates the Windows asset name, URL and SHA-256. This release keeps that
format. Startup checking is enabled by default, runs after about three seconds
and repeats every six hours while the application runs. Downloads and installs
require user action. Live detection will be checked after GitHub publication.

Limits
No real printer commands were issued for this release. A1/P1S physical testing
and real-hardware long-duration connection testing remain outstanding. The SVG
reporter's original file was unavailable; representative failure cases and
regression fixtures were used. Unsupported SVG features remain documented in
the release notes. Passing tests does not establish the absence of all bugs.
