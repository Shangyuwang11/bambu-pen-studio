Bambu Pen 0.22.0

- Added experimental A1 and P1S support for LAN pairing, calibration, streamed drawing and complete-file upload.
- Detects N1 / N2S / C12 instead of treating the shared AP05 controller as A1 mini. Older firmware can use an explicit model selection.
- Model-specific travel limits, return points, lift speeds and full-file settings. P1S uses Z <= 250 mm and conservatively excludes the left 18 mm drawing corridor.
- Printer page shows the actual machine and can switch the canvas to match. Mismatched calibration or artwork cannot command another model.
- Fixed remaining A1-mini-only interface messages and saved the resolved model for automatic reconnect.
- Existing printer credentials, artwork, settings and calibration profiles stay in the same local data directory.

A1 and P1S have passed code and simulated workflow tests, including UI checks. They have not been tested on physical hardware. Windows 10/11 x64. No personal credentials or projects are bundled.
