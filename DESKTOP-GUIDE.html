第一次使用

  1. 双击 EXE。无需另外安装 Python、浏览器或 Bambu Studio。左下角「设置」可以切换简体中文和 English。
  2. 进入「打印机」页。电脑与打印机连接同一局域网，按页面说明启用打印机局域网访问及所需的开发者模式，填写 IP、序列号与访问码。连接成功后，连接信息加密保存在这台电脑上；启用自动连接后会自动重连。
  3. 进入「校准」页，新建校准配置。按向导要求先拆下笔和纸，再归零并抬高。然后放回纸笔，分步调整至笔尖轻触纸面并保存配置。笔架默认在喷嘴正前方 37.5 mm，可在「笔架位置」调整。请以实际夹具测量值为准。
  4. 进入「绘图」页，设置纸张位置和大小、笔芯线宽及绘画速度。导入图片可选择轮廓、排线或自然素描，用橡皮擦去掉局部内容。拖动、缩放和旋转调整位置；右键元素可编辑、复制、居中、调整绘制顺序或删除。
  5. 预演检查路径。超出纸内留白或笔尖可达范围的部分会裁切。整图上传会先把任务交给打印机；等启动确认后才可以断开电脑。分段上传需要保持电脑和网络工作。

下一张、换笔与状态刷新

完成或取消任务后，若纸笔和机器未移动，可继续选择已保存配置。换笔、改变夹具或纸张厚度后，从校准页重新校准该配置。保存配置不会让打印机自动获得真实坐标；归零和手动微调仍需要明确的机器状态。状态看起来没有更新时，点击底部或校准页的刷新按钮。

绘图前的速度是基础速度；运行中的速度档位只调整当前任务，固件会限制实际运动速度。抬笔间隙、短笔画和转角也影响耗时。预览采用实色笔触，线宽用于路径规划与预览，不会改变实体笔芯粗细或压力。

支持范围与数据

支持 A1 mini、A1、P1S 的局域网连接、校准与绘画。A1 / P1S 为实验性适配，尚未实机验证。连接页会显示识别的机型，可点「使用该机型画布」匹配；旧固件无法识别时手动选择实际机型。P1S 绘画避开左侧 18 mm，Z 上限 250 mm。校准配置需要对应实际机型与笔架。此包适用于 Windows 10/11 x64，不支持 macOS、Linux 或 Windows ARM。程序未附发行商数字签名。

连接资料、校准配置与作品存在本机用户目录，更新 EXE 不会清空。共享时只发送公开 EXE，不要附个人数据目录、备份或诊断文件。此发布包不含任何预设私人打印机或访问码。

Get started

  1. Open the EXE. Python, a browser and Bambu Studio are not required. Choose English or 简体中文 in Settings in the lower-left corner.
  2. Open Printer. Connect the computer and printer to the same local network. Enable LAN access and the required developer mode as described on the connection page, then enter the IP address, serial number and access code. Credentials are encrypted on this computer. Enable automatic connection to reconnect on future launches.
  3. Open Calibrate and create a calibration profile. Follow the wizard: remove the pen and paper before homing and lifting, then reinstall them and adjust until the pen just touches the paper. Save the profile. The default mount places the pen 37.5 mm in front of the nozzle; enter your measured offset under Pen mount position.
  4. Open Draw. Set the paper, nib width and drawing speed. Import an image and choose contours, hatching or natural sketch; use the eraser to remove unwanted areas. Drag, resize and rotate objects. Right-click an object to edit, duplicate, center, reorder or delete it.
  5. Preview the paths. Content outside the paper margins or reachable pen area is clipped. Full upload lets the printer execute the file independently after startup is confirmed. Segmented upload requires the computer and network to remain available.

Next drawing, new pen and status

After completion or cancellation, reuse the saved profile if the setup has not moved. Recalibrate from the Calibrate page after changing the pen, mount or paper thickness. A saved profile does not establish physical machine coordinates; homing and manual movement still depend on known machine state. Use Refresh status at the bottom or on the calibration page if the displayed state appears stale.

Base speed applies before drawing. Speed modes during drawing adjust the current job, subject to firmware limits. Pen lift clearance, short strokes and corners also affect drawing time. The preview uses opaque strokes. Nib width controls planning and preview; it cannot change physical line width or pressure.

Compatibility and privacy

LAN connection, calibration and drawing support A1 mini, A1 and P1S. A1 / P1S support is experimental and has not been tested on hardware. Use the matching canvas on the Printer page; manually select the actual model if older firmware cannot identify it. P1S drawing excludes the left 18 mm and limits Z to 250 mm. Calibration profiles must match the printer and pen mount. This package targets Windows 10/11 x64, not macOS, Linux or Windows ARM. The executable is not publisher code-signed.

Printer credentials, profiles and projects remain in the local user data directory across updates. Distribute only the public EXE, not your personal data folder, backups or diagnostic exports. The public package contains no private printer credentials or personal projects.
